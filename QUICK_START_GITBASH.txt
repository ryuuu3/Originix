📋 LANGKAH-LANGKAH CEPAT:

1️⃣  EXTRACT PROJECT
   - Unzip originix.zip
   - Masuk ke folder originix

2️⃣  BUKA GIT BASH
   - Right-click di dalam folder originix
   - Pilih "Git Bash Here"

3️⃣  BUAT GITHUB REPO
   - Buka browser: https://github.com/new
   - Repository name: originix
   - Visibility: Public
   - Klik "Create repository"
   - COPY URL: https://github.com/YOUR_USERNAME/originix.git

4️⃣  JALANKAN DI GIT BASH (ganti YOUR_USERNAME!):

   git remote add origin https://github.com/YOUR_USERNAME/originix.git
   git push -u origin main

5️⃣  AUTHENTICATION
   - Username: YOUR_GITHUB_USERNAME
   - Password: PERSONAL_ACCESS_TOKEN (bukan password!)
   
   Cara buat token:
   - https://github.com/settings/tokens
   - "Generate new token (classic)"
   - Check "repo"
   - Copy token yang muncul!

6️⃣  VERIFY
   - Buka: https://github.com/YOUR_USERNAME/originix
   - Harus ada 27 files!

7️⃣  DEPLOY KE VERCEL
   - Go to: https://vercel.com
   - Import GitHub repo: originix
   - Add environment variables (lihat .env.example)
   - Deploy!
   - LIVE! 🎉
